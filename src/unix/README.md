# 🐧 Unix

Native **Unix** deployable (Linux / macOS) — the same games as `src/browser/`, rendered by the OS instead of a browser.

- **Engine:** Godot (one shared project, exported for Unix) — engine choice is an implementation detail; this folder is the Unix deployable.
- **Assets:** images · fonts · audio come from the [`assets`](../../assets) submodule.
- **Shared:** catalog + puzzle data live at [`src/catalog/`](../catalog) and [`src/data/`](../data).

> Skeleton — the Godot project and export pipeline land here.
